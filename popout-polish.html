The size model (corrected): there is no "natural" width to measure — a column-stretch app fills whatever it's given. So: width is declared (popoutWidth, default 360, clamp 280–720), height is measured with manners (~150ms stability before applying — a "Loading…" dip never collapses the window), floor 120pt, cap ≈ ¾ screen, top edge anchored. Games/canvases that need exact size export popoutSize = {w,h}. Resize: off — a widget isn't a document.

0Launch: opens 1200×800 on the wrong space, never key — and every clone is named "Gen UI Chat"

The window is born at a default 1200×800 then re-anchors bottom-left; activateIgnoringOtherApps is deprecated (grayed lights — the window is never key); and nsh run inherits the app's name → N identical "Gen UI Chat" entries in Cmd-Tab & Mission Control — that's why MC can't bring yours forward. Fix: spawn at final size (--size), named mini app · X, orderFront+activate once; re-↗ raises the live window instead of re-freezing it (which today remounts and loses its state).
